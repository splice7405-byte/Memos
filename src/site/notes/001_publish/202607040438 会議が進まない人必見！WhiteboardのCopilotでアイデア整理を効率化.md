- 00:05 <https://youtu.be/6xJxEdTWamw?t=0m5s> Microsoft Whiteboardの基本概要と操作
    - Microsoft Whiteboardは、オンライン会議での図解説明や複数人でのアイデア出しに最適なデジタルキャンバスツール。
    - 画面上に付箋を貼る、文字を書く、図形を描画する、テキストを入力するなどの直感的な操作が可能。
    - 複数人によるリアルタイムの同時編集に対応している。
    - ブレインストーミングや問題解決など、目的に応じた豊富なテンプレートがあらかじめ用意されている。
- 01:59 <https://youtu.be/6xJxEdTWamw?t=1m59s> Copilotによるアイデアの自動生成
    - 画面右下の「Copilot」ボタンから「候補表示」を選択することで、ブレストのアイデア出しをAIがサポート。
    - プロンプト（例：「Microsoft 365 Copilotの社内推進方法」）を入力すると、自動で複数のアイデアが瞬時に作成される。
    - アイデアは1回につき6つ生成され、「さらに生成する」を押すことで何個でも量産が可能。
    - 生成されたアイデアは、ワンクリックでホワイトボード上に付箋として綺麗に自動挿入される。
    - 1人で考える際も「何も思いつかない」状態を回避でき、企画やマーケティングの初期フェーズに非常に有効。
- 03:33 <https://youtu.be/6xJxEdTWamw?t=3m33s> EdgeのCopilotを併用した社内資料・議事録の参照
    - Whiteboard内のCopilotは直接社内資料を参照できないという制限がある。
    - その解決策として、Edgeブラウザのサイドバーにある「Copilotチャット」を併用する。
    - 議事録や関連資料をEdgeのCopilotに読み込ませ、「ホワイトボードに貼れるように箇条書きにして」と指示。
    - 出力されたテキストをWhiteboardへコピー＆ペーストすることで、既存の社内データをスムーズに落とし込める。
- 04:50 <https://youtu.be/6xJxEdTWamw?t=4m50s> 大量のアイデア付箋を自動で分類・整理
    - メンバー全員が出した大量の付箋を、Copilotがワンタッチで自動グループ化（分類）してくれる。
    - 右下のCopilotボタンから「分類」を選択し、ボード全体の付箋を自動整理。
    - ボード全体だけでなく、特定の付箋だけをドラッグ操作で範囲選択し、一部のデータのみを部分的に自動分類させることも可能。
    - チームリーダーや会議のファシリテーターの整理にかかる時間を大幅に削減できる。
- 05:48 <https://youtu.be/6xJxEdTWamw?t=5m48s> 議論の要約とMicrosoft Loopへの出力
    - 出し合った付箋やメモ書きをベースに、Copilotの「要約」ボタンから一瞬で議論のまとめを作成可能。
    - 要約された内容は自動的に「Microsoft Loop」のページとして生成される。
    - 生成されたLoopページは、後からTeamsの会議録画や他の共有ドキュメントとシームレスに組み合わせて再活用できる。
- 06:32 <https://youtu.be/6xJxEdTWamw?t=6m32s> AIを活用したPowerPoint提案資料への展開
    - 議論を要約したLoopのデータや元の議事録を組み合わせ、外部AI（Claude 3.5 Sonnetなど）を活用して役員向けのPowerPoint資料の構成を作成する。
    - 会社の指定テンプレートがある場合は、あらかじめスライドマスターが適用されたファイルを開いた状態でAIにテキストを作成させるとスムーズ。
    - デザインや構成にこだわりたい場合は、プロンプトであらかじめ配置を指定したり、テキストボックスなどの「箱」を先に出意図通りに配置しておくことで、精度の高いスライドが仕上がる。
